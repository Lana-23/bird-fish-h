## Search & Filter / Поиск и фильтрация

### English

### Search Function

1. Click on the search bar
2. Type the species name (English or Russian)
3. Results filter automatically as you type

**Search tips:**
- Search by common name: "clownfish" or "рыба-клоун"
- Search by Latin name: "Amphiprion"
- Search by characteristics: "blue", "striped", "small"

### Category Filter

1. Click "By Category" view
2. Select a category button:
   - **All Fish/Birds** - Show all species
   - **River/Mediterranean/Tropical** - Filter by habitat
3. View updates automatically

### View Modes

| Mode | Icon | Description |
|------|------|-------------|
| **Category View** | 📁 | Group by habitat/category |
| **List View** | 📋 | Simple list of all species |
| **Family View** | 👨‍👩‍👧‍👦 | Group by biological family |

### Русский

### Поиск

1. Нажмите на строку поиска

3. Результаты фильтруются автоматически

**Советы по поиску:**
- Поиск по названию: "clownfish" или "рыба-клоун"
- Поиск по латинскому названию: "Amphiprion"
- Поиск по характеристикам: "blue", "striped", "small"

### Фильтр по категориям

   - **Все рыбы/птицы** - Показать все виды

## Logging Sightings / Регистрация наблюдений

### English

### How to Log a Sighting

1. Click the **Sightings** tab (📝)
2. Click **"Log a Sighting"** button
3. Fill in the form:
   - **Species:** Select from dropdown
   - **Date:** Choose observation date
   - **Location:** Enter where you saw it
   - **Notes:** Add any additional observations
4. Click **"Add Sighting"**
5. Your sighting is saved automatically!

### Mark as Seen Today

**Quick method:**
1. Find a species in the list
2. Click **"Mark as Seen Today"** button
3. Sighting is logged with today's date

### View Your Sightings

- **Recent Sightings:** Shows latest observations
- **By Species:** Groups sightings by species
- **By Date:** Organizes by observation date

### Delete a Sighting

1. Find the sighting in your list
2. Click the **Delete** button
3. Confirm deletion

### Русский

### Как зарегистрировать наблюдение

1. Нажмите вкладку **Наблюдения** (📝)
2. Нажмите кнопку **"Добавить наблюдение"**
3. Заполните форму:
   - **Вид:** Выберите из выпадающего списка
   - **Дата:** Выберите дату наблюдения
   - **Место:** Укажите где вы видели
   - **Заметки:** Добавьте дополнительные наблюдения
4. Нажмите **"Добавить наблюдение"**
5. Ваше наблюдение сохраняется автоматически!

### Отметить как виденное сегодня

**Быстрый способ:**
1. Найдите вид в списке
2. Нажмите кнопку **"Отметить как виденное сегодня"**
3. Наблюдение регистрируется с сегодняшней датой

### Просмотр ваших наблюдений

- **Последние наблюдения:** Показывает последние наблюдения
- **По видам:** Группирует наблюдения по видам
- **По дате:** Организует по дате наблюдения

### Удалить наблюдение

1. Найдите наблюдение в вашем списке
2. Нажмите кнопку **Удалить**
3. Подтвердите удаление

## Troubleshooting / Решение проблем

### English

### Common Issues

**Problem:** App doesn't load
- **Solution:** Refresh the page (F5 or Ctrl+R)

**Problem:** Images not showing
- **Solution:** Check your internet connection, images load from server

**Problem:** Can't save sightings
- **Solution:** Clear browser cache and try again

**Problem:** Language not changing
- **Solution:** Refresh the page after selecting language

**Problem:** Data lost after refresh
- **Solution:** Data is stored in browser storage (IndexedDB). Clearing browser cache will delete data. Consider exporting your data regularly.

### Browser Compatibility

| Browser | Status |
|---------|--------|
| Chrome | ✅ Fully supported |
| Firefox | ✅ Fully supported |
| Safari | ✅ Fully supported |
| Edge | ✅ Fully supported |

### Data Storage

**English:**
Your sightings are automatically saved to browser storage (IndexedDB) and persist through cache clears.

**Русский:**
Ваши наблюдения автоматически сохраняются в хранилище браузера (IndexedDB) и сохраняются после очистки кеша.

### Contact Support

For issues or questions, please contact the development team.

### Русский

### Распространённые проблемы

**Проблема:** Приложение не загружается
- **Решение:** Обновите страницу (F5 или Ctrl+R)

**Проблема:** Изображения не отображаются
- **Решение:** Проверьте подключение к интернету, изображения загружаются с сервера

**Проблема:** Не сохраняются наблюдения
- **Решение:** Очистите кеш браузера и попробуйте снова

**Проблема:** Язык не меняется
- **Решение:** Обновите страницу после выбора языка

**Проблема:** Данные потеряны после обновления
- **Решение:** Данные хранятся в хранилище браузера (IndexedDB). Очистка кеша браузера удалит данные. Рекомендуется регулярно экспортировать ваши данные.
